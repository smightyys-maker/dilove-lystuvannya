## 📌 Зміст проєкту

1. **Теорія коротко: чеклист із 6 правил ділового листування**
   - Точність і конкретність (дати, номери, суми).
   - Лаконічність і видалення «води».
   - Нейтральний, доброзичливий тон.
   - Заборона емоційно забарвленої й сленгової лексики.
   - Логічна тричастинна структура (вступ, суть, заключна частина).
   - Мережевий етикет (Netiquette) для електронної пошти.

2. **Обов’язкові реквізити та формуляр-зразок (ДСТУ 4163:2020)**
   - 10 обов'язкових елементів офіційного листа (назва, довідкові дані, дата, вихідний номер, адресат, заголовок, текст, додатки, підпис, виконавець).
   - Робота із цифровими шаблонами у Google Документах та MS Word (.dotx).

3. **Порівняльна таблиця «як треба / як не треба»**
   - 10 типових ситуацій та аналіз помилок у звертаннях, формулюванні прохань, реакції на претензії, структурі, темі листа та додатках.

4. **Практична частина: виконані завдання**
   - Інструкція з вбудовування документів Google Docs та PDF.
   - Зразок відредагованого листа-запиту з усіма реквізитами (з можливістю швидкого копіювання).

5. **Саморефлексія**
   - Відповіді на ключові питання щодо складнощів офіційного стилю та практичної цінності навичок у навчанні й кар'єрі.

6. **Цікаві практичні завдання**
   - *Завдання 1.* «Адвокат бренду» — кейс-симуляція (офіційний лист-вибачення з компенсацією).
   - *Завдання 2.* «Детектив помилок» — аналіз і редагування тексту «стажера» з таблицею «було → стало».
   - *Завдання 3.* «Конструктор шаблону» — розробка цифрового бланка та мотиваційного листа для гранту.

## 🚀 Як опубліковано на GitHub Pages

Сторінка налаштована для публікації через GitHub Pages:
- **Джерело (Source):** гілка `main`
- **Шлях (Path):** `/` (кореневий каталог)
- **Файл точки входу:** `index.html`
- **Пряма адреса сайту:** [https://smightyys-maker.github.io/dilove-lystuvannya/](https://smightyys-maker.github.io/dilove-lystuvannya/)

### Якщо потрібно перевірити чи переналаштувати в GitHub:
1. Перейдіть у вкладку **Settings** репозиторію на GitHub.
2. У лівому бічному меню оберіть **Pages**.
3. У блоці **Build and deployment** має бути встановлено:
   - **Source:** *Deploy from a branch*
   - **Branch:** `main` (папка `/ (root)`)
4. Посилання на готовий сайт відображається зверху: `https://smightyys-maker.github.io/dilove-lystuvannya/`.

## 💻 Локальний перегляд

Ви можете відкрити сторінку безпосередньо у веб-переглядачі:
- Відкрийте файл `index.html` у будь-якому браузері (Chrome, Firefox, Safari, Edge), або
- Запустіть локальний сервер у терміналі:
  ```bash
  python3 -m http.server 8000
  ```
  та перейдіть за адресою `http://localhost:8000`.
